# Megalomania Remake 🚀

A high-precision 8-bit space shooter (shmup) built with vanilla JavaScript and HTML5 Canvas, inspired by the classic Atari **Megamania**.

![Game Screenshot Placeholder](https://via.placeholder.com/800x450.png?text=Megalomania+Remake+Gameplay)

## 🎮 Features

- **Precise Controls**: Instant-stop movement for arcade accuracy.
- **Energy Management**: Strategic fuel system with wave-completion bonuses.
- **Retro Aesthetics**: 8-bit procedural sprites with modern neon-vibrant effects.
- **Procedural SFX**: Authentic square-wave and noise-based sound effects via Web Audio API.
- **Progressive Difficulty**: Scaling speed and complexity across 5 unique enemy types.

## 🕹️ How to Play

1. **Clone the repository**:
   ```bash
   git clone https://github.com/rdcl735/remake-megamania.git
   ```
2. **Serve the project**:
   - Using Python: `python -m http.server 8000`
   - Using Node (Vite): `npm install && npm run dev`
3. **Open in browser**: `http://localhost:8000` or `http://localhost:5173`

### Controls
- **WASD / Arrow Keys**: Move Ship
- **Spacebar**: Shoot (Max 2 projectiles) / Start Game

## 🛠️ Tech Stack

- **Core**: HTML5, Vanilla JavaScript (ES Modules)
- **Styling**: CSS3 (Glassmorphism & Neon Effects)
- **Rendering**: HTML5 Canvas API
- **Audio**: Web Audio API
